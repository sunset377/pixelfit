# PixelFit | 像素健身养成小游戏

试玩：https://sunset377.github.io/pixelfit/

此仓库托管 Web 试玩构建，开发源码在本地维护。黑白灰玻璃入口、三套分身选择、彩色像素健身房。完成 20 秒哑铃出拳训练，自动生成黑白成长小票，存图或系统分享。固定 9:16 竖屏，支持减少动态偏好。

进度只保存在当前浏览器，不上传服务器。角色数值是游戏属性，不代表真实健康数据。广告、支付、云存档、衣柜和体力恢复尚未接入。

场景、彩色器械、虚构怪物和图标为项目内 SVG；人物沿用用户本地素材（未提供独立素材复用许可）。界面使用 CSS 与原生 Web Animations，无额外动效库。字体为 Fusion Pixel Font（SIL OFL-1.1），完整许可随 assets/NOTICE-*.txt 分发。
